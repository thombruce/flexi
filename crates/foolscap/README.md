# foolscap

Shared plumbing for the [flexi](https://github.com/thombruce/flexi) family of plaintext CLI tools: XDG path discovery, toml config loading, line-oriented file I/O with atomic rewrites, and `$EDITOR` launching.

This is an internal support library for flexi, clocking, calchemy, bagg, holler, and toodles. It's published only because those tools are, and its API is not intended for general use.
